# J-WOO 5.0 Vocal Studio — integration candidate

Status: SOURCE_IMPLEMENTED / REAL_SINGING_NOT_VERIFIED. No voicebank binaries included, no model rights implied, no deployment authorization. Base b127e9b.

## Local setup
1. Install OpenUtau from https://www.openutau.com/ and a licensed Korean DiffSinger voicebank from its official site. Chiaki: https://chiaki.ch/en/character/chiaki (credit Vocal: Chiaki, no redistribution). Male bank must be obtained and reviewed separately; never label a pitch-shifted female model male.
2. A compatible headless OpenUtau API with DiffSinger renderer, Korean phonemizer and vocoder is required for one-click rendering. Candidate protocol: https://github.com/stuffed-cat/openutau-api (GET /api/singers, GET /api/phonemizers, POST /api/project/render multipart file). Its repository does not have a verified redistribution license; do not bundle or copy it. Installation, runtime compatibility and real singing are NOT verified. Run an independently authorized compatible backend only on 127.0.0.1:19471 with API-key authentication enabled. Do not expose its destructive endpoints to browsers or networks.
3. Copy models.example.json to models.local.json; populate exact installed singer IDs, reviewed model terms, explicitly supported expressions, gender and credit. Set usageAccepted only after review. No model is advertised merely because a preset exists.
4. Node 22+; launch from repository root with JWOO_ORIGIN set to the exact HTTPS site origin (or http://127.0.0.1:5173 for development), JWOO_VOCAL_KEY a locally generated 24+ character random key, OPENUTAU_API_KEY the separate backend key, and OPENUTAU_URL=http://127.0.0.1:19471. Run node vocal-engine/server.mjs. Do not commit keys or local model config.
5. Open the site, select VOCAL STUDIO, enter the local bridge key, connect, select an installed voice, generate. Browser local-network permissions may be required; if hosted-page loopback access is blocked, use Vite local preview with its exact origin. The bridge allows only the configured origin, loopback Host and key; no arbitrary paths, model files, or external calls. API key is not persisted by browser code.
6. If one-click rendering is unavailable, use the USTX export with a discovered model and open it in official OpenUtau to render WAV manually. This is a fallback, not a substitute for completing the live engine.

## Scope and gates
Read-only MusicXML snapshot, selected part/voice/staff/lyric verse; exact 480 PPQ timing, tempo changes, rest gaps, tie merging, explicit rejection of unsupported rhythms/repeats/polyphony/missing lyrics. Range exports are relative to selected first bar; full export preserves leading silence. Input limited to Hangul lyrics and explicit continuation. Model-specific controls are enabled only by local configuration. Presets control curves, not semantic human emotion. No accompaniment. Audio returns only after WAV checks; actual audible identity, pronunciation, expression and timeline synchronization still require listening and independent checks. The UI displays active bar number, not a highlighted score cursor. Partial generation creates a separate clip; it does not splice audio into existing output.

Acceptance before merge: existing CI pass; approved female AND male Korean model installed and discovered; real sung phrase generated from edited MusicXML; natural Korean pronunciation evaluated; distinguishable gender models and audible expression variations; original rhythm/leading silence/tempo alignment verified in Logic; cancellation/timeout and browser compatibility tested. No claims of full completion until these gates pass.
